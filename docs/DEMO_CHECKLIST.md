## 🛠️ BEFORE DEMO (Pre-Flight Checks)

- [x] Node.js server running (`npm run serve` on port 3001)
- [x] Web browser open to `http://localhost:3000` or `http://localhost:3001`
- [x] Internet connection active (or Demo Mode toggled ON)
- [x] Groq API health check verified (`/api/health` returns status 200 OK)
- [x] Browser console clean (0 uncaught JavaScript errors)
- [x] "Load Demo Data" button verified and populates Hackathon dataset
- [x] Screen resolution and browser zoom set to 100%
- [x] Backup tab open in Demo Mode in case of Wi-Fi latency
