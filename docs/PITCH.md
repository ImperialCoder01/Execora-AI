## 🚀 60-Second Pitch

> *"Teams run on communication, but work runs on execution. When a team finishes a sync meeting, information is buried inside transcripts. Critical tasks stay unassigned, deadlines get forgotten, and unresolved bugs cause last-minute panic.*
>
> *Standard LLMs generate conversational summaries, but summaries don't get work done. **ActionFlow AI** changes that. By ingesting raw transcripts or notes, ActionFlow executes schema-enforced structured extraction. It extracts tasks with assignees, identifies upcoming deadlines, flags unassigned gaps, and calculates a transparent confidence rating.*
>
> *Crucially, ActionFlow includes a **Grounded Q&A Engine** that answers questions strictly from original quotes — distinguishing facts from recommendations — and a **Human Approval Workflow** that gives humans control over AI execution. Don't summarize your work. Execute it with ActionFlow AI."*

## 🎯 2-Minute Pitch

> *"Good afternoon judges. I'm presenting **ActionFlow AI** under Problem Statement 02: AI Agent for Real-World Productivity.*
>
> ### The Core Problem
> *Information overload is the single biggest productivity killer in modern engineering and business teams. We communicate across meetings, emails, and PRDs, but then we waste hours manually extracting tasks, dates, and assignees. Worse, critical items like unassigned video creation or unresolved API bugs slip through the cracks.*
>
> ### The Solution
> *ActionFlow AI is an execution assistant that automatically turns unstructured text into structured, actionable work specifications.*
>
> ### Key Pillars:
> 1. **Structured Work Extraction**: Extracts tasks, assignees, priorities, deadlines, and decisions with exact source quote citations.
> 2. **Information Gap Detection**: Automatically flags unassigned tasks and missing deadlines before they cause project failure.
> 3. **Grounded Q&A Engine**: Bounded strictly to original source quotes with zero hallucination. It explicitly labels answers as FACT vs RECOMMENDATION, and says 'Information Unavailable' when data is missing.
> 4. **Human-In-The-Loop Action Plan**: Synthesizes a step-by-step resolution path requiring explicit human approval before execution.
>
> ### Tech Architecture & Performance
> *Built with React, TypeScript, Express, and Groq LLaMA 3.3 70B, delivering responses in under 1.2 seconds. It includes a complete offline Demo Mode for zero-downtime reliability.*
>
> *ActionFlow AI turns messy information into executable work. Thank you!"*
