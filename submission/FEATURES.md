# Key Features Summary — ActionFlow AI

1. **Unstructured Text & File Ingestion**: Ingest raw meeting notes, emails, or dropped text files.
2. **Schema-Enforced Task Extraction**: Extracts task titles, assignees, priorities (High/Med/Low), deadlines, statuses, and source quotes.
3. **Deadline & Decision Tracking**: Maps scheduled dates, times, and team decisions.
4. **Information Gap Detection**: Flags unassigned tasks and ambiguous deadlines automatically.
5. **Transparent AI Confidence Gauge**: Displays 0-100% confidence rating backed by detailed reasoning.
6. **Prioritized Action Plan**: Sequential step execution path with Human-in-the-Loop approval toggles.
7. **Grounded Q&A Assistant**: Zero-hallucination document chat with Fact vs Recommendation badges.
8. **Today's Plan Synthesizer**: Modal compiling daily schedule with 1-click Markdown copy and JSON export.
9. **Zero-Dependency Demo Mode**: Built-in offline dataset ensuring zero downtime during presentations.
